# Egypt Atlas v0.16 — дополнение карты и фото

**Это редакторская сборка, не финальный релиз.** База: v0.15. 12 направлений, 73 исторических рассказа и прежняя настройка Microsoft Edge TTS Svetlana остались без изменений.

## Запуск и аудит
1. Распакуйте архив `Egypt_Atlas_v016_Content_Audit.zip` в новую папку.
2. Откройте `index.html` — приложение с новыми ориентирами и ссылками на реальные фото-кандидаты (интернет необходим для фото и онлайн-карты).
3. Откройте `audit.html` — визуальный перечень всех 73 точек, фильтры «нет GPS», «нет фото», ссылки на геоисточник и Wikimedia Commons.
4. `data/audit_73.csv` — таблица координат, статусов, фотоисточников и дальнейших действий для каждой остановки. `data/photo_review.csv` — список лицензий и авторства для проверки.

## Состояние
- GPS-ориентиры на интерактивной OSM-карте: 32/73 (было 11/73). Это ориентиры объекта или области, не проверенные точки стояния и не входы. На обзорных SVG-схемах могут быть условные кружки; их нельзя считать настоящими GPS-маркерами.
- Ссылки на кандидатные реальные фото: 65/73 (было 9/73). **Ссылки не являются проверенными и встроенными изображениями**; при ошибке загрузки доступны SVG-заглушки. Нужна проверка соответствия объекта, доступности файла, правообладателя, лицензии и оформления атрибуции.
- Неразмеченных GPS-мест: 41; без кандидата фото: 8. Перечни ID — `AUDIT_CONTENT_v016.md`.
- Интерьеры GEM, Библиотеки, Кайтбея и подземных катакомб требуют планов, а не уличного GPS. Для GEM: https://gem.eg/visit/plan-your-visit/museum-maps/ . Подводить туриста к спорным GPS-точкам запрещено.

## Фото и офлайн
Дополнительно можно запустить `DOWNLOAD_PHOTOS_WINDOWS.bat` (или `python download_commons_photos.py`) для **скачивания тестовых копий кандидатов** в `photos/real/` и отчёта `data/photo_download_results.csv`. Этот шаг **не подменяет** фото в приложении и не означает разрешение распространять их. Перед включением офлайн-изображений необходимо отдельно проверить происхождение, условия лицензии, атрибуцию, качество и размеры.

## Зафиксированные настройки озвучки
Голос `ru-RU-SvetlanaNeural`, обычный текст без меток ударения; согласованное произношение «Рамзес» в TTS и правильное имя фараона «Сети» сохраняются. Файлы генератора и уже существующие MP3 не изменены.

Полный отчёт: `AUDIT_CONTENT_v016.md`.
