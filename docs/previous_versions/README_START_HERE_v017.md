# Egypt Atlas v0.17 — готовая сборка для просмотра и тестирования

## Запуск

**Проще всего:** распакуйте весь ZIP и дважды нажмите `index.html`. На странице выберите достопримечательность, затем «Карта»; используйте «Схема остановок» для всех 73 номеров. На карте OSM показаны только те внешние GPS-ориентиры, которые ранее имели источник. Нажмите на номер на схеме, чтобы открыть рассказ.

**На телефоне / для PWA и GPS:** разместите папку на HTTPS-хостинге либо на компьютере запустите `START_LOCAL_SERVER_WINDOWS.bat`, затем откройте http://localhost:8000 . Геолокация через интернет/HTTPS требует разрешения пользователя.

## Что действительно работает
- 12 направлений и 73 текстовых рассказа.
- 73 кликабельных номера на схемах остановок. Карнак — ориентировочная архитектурная схема, остальные 11 — только последовательность рассказов, **НЕ архитектурные планы**.
- 32 GPS-ориентира на интерактивной карте OSM; за остальные 41 нельзя выдавать точные координаты. Внутренние витрины, катакомбы и залы не привязаны к GPS.
- Для всех 73 карточек подобраны интернет-ссылки на фотографии или соответствующие тематические изображения. Из них 4 официальных фото GEM (правообладатель GEM, для публичного показа требуется уточнить права). Другие изображения Wikimedia Commons, атрибуцию необходимо проверить перед публикацией. Некоторые снимки иллюстративные, а не точная позиция экскурсии.
- Локальные тексты доступны без сети; фото и OSM требуют интернет, если заранее не лицензировать и не упаковать изображения.
- Поддерживается HTML Audio с готовыми MP3 и запасной системный голос. **MP3 Светланы НЕ включены в ZIP**: в среде сборки нет доступа к Edge TTS. На Windows `GENERATE_ALL_WINDOWS.bat` сгенерирует 73 MP3 при доступе к сети. Скрипт использует неофициальный Edge endpoint, условия публичного использования записей следует проверить.

## Источники и контроль
- `photo-sources.html` — источник и статус картинки по каждой остановке.
- `data/content_status_v017.csv` — все 73 метки, фото, GPS-статусы, где слушать.
- `https://gem.eg/visit/plan-your-visit/museum-maps/` — официальный план GEM; текущая маршрутная схема в приложении **не заменяет** его.
- `https://huss.aucegypt.edu/about/centers/theban-mapping-project` — Theban Mapping Project (Долина царей).
- `https://www.touregypt.net/featurestories/komelshuqafa.htm` — описание первого уровня катакомб.

**Ограничение перед публичным релизом:** нужен ручной QA геометрии, фотолицензий, доступности маршрутов и очная проверка внутренних схем. Эта сборка — функциональный офлайн-путеводитель по текстам с онлайн-изображениями, НЕ сертифицированная навигационная карта и НЕ полностью автономный медиа-пакет.
