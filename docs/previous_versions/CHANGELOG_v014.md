# Egypt Atlas v0.14 — голос Svetlana, обычный текст

**Основа:** полный Egypt Atlas v0.13. Карты, каталоги, тексты и карточки не менялись.

- Основной голос: `ru-RU-SvetlanaNeural`, темп `+0%`.
- Без Unicode-ударений, `+`, транскрипций и SSML.
- Только при генерации MP3: формы имени «Рамсес» → «Рамзес» (все падежи).
- `KAR-04`: «при Сети Первом» → «при фараоне Сете Первом».
- `VAL-05`: «Гробница Сети Первого» → «Гробница фараона Сете Первого»; «Сети правил» → «Этот фараон правил».

**Важно:** «Сети» — общеупотребительная форма имени фараона, а «Сете» здесь только экспериментальное написание для TTS. В карточках исторически корректное написание сохранено. Не применять эту замену к богу Сету.

### Применение к существующей копии v0.13

Можно скопировать в папку проекта только три файла из v0.14: `generate_all.py`, `tts_pronunciation.py`, `tts-pronunciation.json`, заменив `generate_all.py`. Остальное, включая уже сгенерированные MP3, останется на месте.

После этого запусти обычный `GENERATE_ALL_WINDOWS.bat`: генератор сам перегенерирует только затронутые MP3 (поскольку хеш считается от изменённого дикторского текста). Если нужен быстрый тест только Карнака: `python generate_all.py --only KAR-04`.

Результат для конкретных фраз **не проверен на слух**: замены отражают пользовательские предпочтения после бенчмарка. Если Светлана скажет «Сете» неестественно, замену легко поправить в `tts-pronunciation.json`, и соответствующие MP3 перегенерируются.

Условия использования Edge TTS для публичного распространения аудио требуют отдельной проверки; данный метод предназначен для локального прототипирования.
