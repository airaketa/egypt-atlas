# Egypt Atlas v0.15 — восстановлено имя «Сети»

Основа: v0.14. Голос `ru-RU-SvetlanaNeural`, обычный текст без меток ударения.

- Убраны экспериментальные TTS-замены с «Сети» на «Сете», а также связанные с ними перефразирования в `KAR-04` и `VAL-05`.
- Диктор читает оригинальный текст с именем «Сети»: «при Сети Первом», «Гробница Сети Первого», «Сети правил».
- Сохранены только варианты произношения имени «Рамсес» → «Рамзес» в TTS-тексте (включая падежные формы). Отображаемый текст не меняется.
- `generate_all.py` и исходники рассказов остались без изменений.

## Если уже установлен v0.14

Достаточно заменить **один файл** `tts-pronunciation.json` из патча (или полной версии) и запустить `GENERATE_ALL_WINDOWS.bat`. Система хеширования TTS-текста перегенерирует изменившиеся файлы `KAR-04` и `VAL-05`, если они уже были озвучены с экспериментальными подстановками.

Если нужно проверить только их, запусти:

```bat
.venv\Scripts\python.exe generate_all.py --only KAR-04
.venv\Scripts\python.exe generate_all.py --only VAL-05
```

Если `.venv` нет, используй тот Python, которым обычно запускаешь генератор.
