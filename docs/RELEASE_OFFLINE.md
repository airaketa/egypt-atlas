# Самодостаточный офлайн-релиз Egypt Atlas

## 1. Подготовить все медиа

По очереди запустить:

1. `GENERATE_ALL_WINDOWS.bat` — 82 MP3.
2. `DOWNLOAD_PHOTOS_WINDOWS.bat` — 82 фотографии остановок.
3. `DOWNLOAD_CARTOUCHE_PHOTOS_WINDOWS.bat` — 6 фотографий для раздела о картушах.
4. `DOWNLOAD_ALL_MAPS_WINDOWS.bat` — 12 архивов PMTiles.

Повторный запуск загрузчиков безопасен: готовые файлы пропускаются.

## 2. Собрать Release ZIP

Запустить `PACK_MEDIA_WINDOWS.bat`. Строгая проверка требует:

- 82 актуальных MP3;
- 82 фотографии остановок;
- 6 фотографий картушей;
- 12 валидных файлов `maps/offline/*.pmtiles`.

Результат — `egypt-media.zip`. Аудио, фотографии и карты не добавляются в Git.

## 3. Опубликовать на GitHub

1. Создать draft-релиз с тегом `media-v1`.
2. Прикрепить `egypt-media.zip`.
3. Опубликовать релиз.

Workflow `Publish Egypt Atlas` скачает архив, проверит контрольные суммы и полноту, распакует медиа внутрь сайта и опубликует GitHub Pages. Если заменён файл уже существующего релиза, нужно вручную запустить workflow через `Actions → Publish Egypt Atlas → Run workflow`.

В опубликованной сборке используются относительные URL:

- `./audio/ID.mp3`;
- `./photos/real/ID.ext`;
- `./maps/offline/TOUR.pmtiles`.

## 4. Установить на телефон

1. Открыть сайт GitHub Pages по HTTPS.
2. Установить его на главный экран как PWA.
3. Пока интернет доступен, нажать кнопку офлайн-загрузки в правой части верхней панели.
4. Дождаться сообщения «Аудио, фотографии и интерактивные карты готовы офлайн ✓».
5. Включить авиарежим и проверить несколько карточек, аудио и интерактивную карту.

Установка PWA кэширует оболочку приложения. Большой медиапакет загружается отдельно кнопкой, чтобы браузер не начинал незаметную загрузку десятков мегабайт при первом открытии.
